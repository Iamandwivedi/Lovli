# Lovli — Project Overview

AI dating-chat reply coach for India. Mobile-first, dark, calm, private.

## Core flow

Upload screenshot OR paste chat → choose reply language → (optional) customize platform / vibe / memory → generate 3 replies → copy & send.

## Product constants (shared across web + mobile)

### Platforms (exactly 3)
- Instagram
- Dating platform
- WhatsApp

### Reply languages
- English
- Hinglish
- Hindi + English mixed

### Vibes
- Playful
- Flirty
- Sincere
- Respectful
- Confident

### Tone label mapping (shown on each result card)
| Vibe | Tone label |
|---|---|
| Playful | PLAYFUL |
| Flirty | SMOOTH |
| Sincere | SINCERE |
| Respectful | RESPECTFUL |
| Confident | CONFIDENT |
| Fallback | WARM |

### Bottom tabs (exactly 3)
- Reply
- Pro
- Memory

Settings is **NEVER** a bottom tab — accessible only via the top-right cog.

### Free vs Pro (binding copy)
**Free:** 8 generations/day · 3 replies each time · Basic vibes · Standard memory.
**Pro:** Unlimited generations · Advanced memory · More reply styles · Early access to new AI features.
CTA: **"Get Early Access"** (never "Upgrade" / "Buy" / "Subscribe"). No human-coach / wingman / dating-expert language.

### Memory soft labels
| Stored field | Label shown to user |
|---|---|
| `likes` | Good to remember |
| `dislikes` | Things to avoid |
| `communication_style` | How they usually talk |
| `inside_jokes` | Inside jokes |
| `important_dates` | Important moments |
| `best_approach` | What feels right |
| `notes` | Your notes |

Empty memory fields are hidden in the card.
