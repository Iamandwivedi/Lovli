IDENTITY (unchanged — reuse exactly)

  headers + Plus Jakarta Sans body. Premium through generous SPACE.

GUIDING PRINCIPLES (the whole point)
- Coach-first, not tool-first. Reduce cognitive load — the user shouldn't wonder "what do I
  type?"; it should feel like "Lovli already gets it."
- Emotion-driven. Meet the user where they are (anxious, excited, overthinking).
- Always explain the WHY. Every read/reply shows what Lovli is noticing and the next move.
- Warm, human, first-person voice everywhere (see VOICE below) — never robotic.
- HONESTY (hard rule): qualitative reads only — NO numeric confidence, NO "92%", NO percentage
  meters, NO relationship "score". NO fabricated social proof or user counts (pre-launch).

NAVIGATION — 4 tabs: **Reply · Ask Lovli · Memory · More** (active = lavender). "Ask Lovli" is
a new dating-coach chat tab; remove "Ask Lovli anything" from the More grid (it lives here now).

SCREENS

1. Reply · Home (emotion-first entry)
   - Optional emotional check-in row up top: "How are you feeling?" with soft chips 😊 Excited ·
     😔 Confused · 😰 Overthinking · ❤️ Falling for someone · 💔 Healing · 😎 Just curious
     (tapping one warms the copy; fully skippable so power users go straight to paste).
   - Warmer prompt: "What's happening?" / "Tell me what happened." / "Show me the conversation."
     (retire "Stuck on what to say back?").
   - Compact upload-a-screenshot row + "Or paste the chat here…" field. White "✦ Get replies".

2. Reply · Input (progressive disclosure)
   - After paste/upload, don't show every control at once. Flow: paste → Lovli "reads" → asks
     **"What do you want?"** with intent chips: Reply · Understand · Flirt · Set boundaries ·
     End it · Save the vibe.
   - Only after "Reply" is chosen, reveal the tone step — as OUTCOME chips, not abstract tones:
     "Make them smile · Keep the mystery · Sound confident · Don't look desperate · Be funny ·
     Stay casual · Be mature." (People know the result they want, not the "tone".)

3. Reply · Generated (the biggest upgrade — explain the why)
   - Each reply is a card: text + Copy · Edit · Regenerate.
   - Below/above it, a **"Here's what I'm noticing"** insight block (qualitative, NO numbers):
     the read (a Warm / Mixed / Cold pill), 2–3 green-flag/observation bullets, "what's really
     going on", and an **"If I were your wingman…"** next-move line.
   - Alternative replies as quick chips: Funny · Romantic · Confident · Short · Long.

4. Reply · Generating (animated progress)
   - Pulsing ✦ with staged, visible progress lines: "Reading the message… → Checking the vibe…
     → Understanding context… → Finding the best reply… → Writing naturally…"

5. Ask Lovli (NEW chat tab)
   - A warm dating-coach chat: friendly first-person greeting ("Hey — what's on your mind? Tell
     me the situation, or ask me anything."), suggested starter prompts ("Help me respond to a
     message", "Is this a red flag?", "How do I restart a dead convo?"), chat bubbles (Lovli =
     lavender-accented, glowing ✦ avatar), and a message input. Feels like texting a wise friend.

6. Decode (make this killer feature BIG — qualitative)
   - Prominent "Overall vibe" read with a QUALITATIVE meter (e.g. a 3-segment bar emphasized
     toward "Leaning interested" / "Mixed signals" / "Not into it") — words, NOT percentages.
   - Then: Positive signs · Watch-outs · What's really going on · Your next move · Likely
     outcome. High perceived intelligence, all honest.

7. More · Tools (categorized, real features only)
   - Keep the 3 airy sections from Lovli Dark — **Make sense of it · Make a move · Work it out**
     — with the real tools (Decode the situation, Read the signals, The other side · Glow up my
     reply, What should I do · Red flag check, Settle the fight, Fair verdict, Breakup clarity).
     Thin lavender line icons on dark glass. (Ask Lovli now lives in its own tab.)

8. Memory (restyle only — no auto-detect) + Memory Detail (relationship timeline)
   - List: people as summary cards (avatar, name, stage, meta, 1–3 fact chips). White "✦ Add a
     memory" CTA. Warm empty state.
   - Detail: a **relationship timeline** — Met · First date · Mentioned dog · Birthday · etc.
     as a vertical time-lined list, plus their facts as grouped chips. Manual entry (Lovli
     "keeps track" of what you save) — do NOT imply auto-extraction from chats.

9. Premium (sell outcomes + before/after)
   - Before → after framing: "Overthinking every text" → "Always know what to say."
   - Outcome checks: Unlimited replies · Relationship memory · Deeper message decoding · Ask
     Lovli anytime · Priority AI. Yearly (best value, 2 months free) + Monthly. White "✦ Start
     7 days free". No fabricated stats.

10. Onboarding (goal-based, personal)
    - Lead with **"What's your goal?"** — Find a relationship · Fix things with someone · Dating
      apps · Talking stage · Marriage · Recover after a breakup. Warm, first-person, one
      question per airy screen; ends on a pulsing-✦ "Setting up your wingman…" theatre.

11. Welcome (honest — no fake proof)
    - Beautiful hero + glowing ✦ mark, a value line ("Your wingman for every text, talk &
      situationship"), and a "Private by default" reassurance. NO "100k users / 4.9★" — omit
      until real.

12. Settings (fleshed, realistic)
    - Grouped rows on dark: Account (email, plan badge) · Preferences (default language, default
      vibe, perspective) · Privacy · Delete memories · Notifications · Restore purchases · Log
      out. One lavender accent per row. (Skip features that don't exist yet, e.g. voice.)

MICROINTERACTIONS (tasteful, not noisy)
- Button press → subtle scale. Reply copied → gentle ✦ sparkle toast. Memory saved → floating
  toast. Decode finished → soft lavender glow. Cards appear → light stagger. Every success feels
  quietly rewarding — restrained, premium, never confetti-spam.
