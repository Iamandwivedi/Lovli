Grain — mandatory on dark

Dark gradients band badly on cheap panels. A 3.5% monochrome noise layer over the stage kills it. One layer, document-level, pointer-events:none.

feTurbulence fractalNoise
baseFrequency .85 · octaves 3
opacity .035 · blend overlay
Performance budget
  • Two live blur layers per screen, maximum — usually tab bar plus one panel.
  • Never blur inside a scrolling list. Memory rows are E1 solid.
  • Android below API 31 and low-power mode fall back to a pre-baked fill #171827, no blur.
  • Orbs are static CSS radials on mid-range; drift animates on iOS only.
Reduce transparency

Honoured system-wide. Glass collapses to its solid twin; nothing else moves. Body text holds 4.5:1 against the effective glass colour in both states.
